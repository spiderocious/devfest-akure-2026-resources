# DevFest Akure 2026 · resources page

A one-page site collecting the slides, live demos, recordings and code for the workshop *Designing Offline Enabled Data Intensive Web Apps: Web Workers, Cache Strategy, Storage Tiers, Sync, Queues, and Runtime Observability*.

Static HTML in `index.html`, recordings in `videos/`. Deployed on Netlify; `netlify deploy --prod --dir . --no-build` from this folder publishes it.
